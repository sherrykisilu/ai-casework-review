# Contributing

Thank you for improving this independent portfolio project.

1. Create a focused branch and keep changes scoped.
2. Never commit credentials, customer data, employer code, or confidential case text.
3. Install backend and frontend dependencies, then run `pytest`, `python -m evaluation.run`, `npm test`, and `npm run build`.
4. Add or update tests for behavior changes. AI behavior changes must include versioned evaluation fixtures and explain expected metric movement.
5. Keep findings evidence-grounded, surface fallbacks and failures, preserve human review, and document new privacy, safety, security, or cost tradeoffs.
6. Open a pull request describing the change, validation performed, and limitations.
